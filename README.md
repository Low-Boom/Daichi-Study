# Daichi Study

Japanese verb-form practice for Daichi 1 and 2.

## Tools

- **Verb form quiz** (`Daichi verb form quiz.html`): conjugation and keigo forms from Daichi 1 and 2.
- **Verb pair drill** (`Daichi verb pair drill.html`): 174 自動詞・他動詞 pairs from 『初級から中級への日本語ドリル 文法』 pages 18–21, in the 10 pattern groups of the book. It drills five skills for each pair: partner, が/を use, meaning, kanji and reading. Each skill has its own spaced-review schedule. Progress stays in the browser (localStorage).

## GitHub Pages

Visit the site at <https://low-boom.github.io/Daichi-Study/>.

To publish it, open the repository's **Settings → Pages**, choose **Deploy from a branch**, then select branch **main** and folder **/(root)** and save.

The quiz includes semantic page landmarks, a skip-to-content link, visible keyboard focus, and accessible names for its controls. The root landing page also provides a keyboard-accessible link to the quiz.
